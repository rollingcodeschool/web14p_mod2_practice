# Prácticas de JavaScript y TypeScript — Comisión Web14p

Este repositorio es un proyecto educativo para aprender y practicar los fundamentos de **JavaScript y TypeScript** durante la cursada de la Comisión Web14p de RollingCode. Incluye ejemplos, ejercicios y apuntes organizados por tema.

## Contenido de `fundamentos/`

- `01-variables`: declaración de variables (`let` y `const`) y tipos de datos básicos.
- `02-operadores`: operadores de asignación, comparación y lógica, además del operador ternario.
- `03-objetos_if`: objetos, propiedades, interfaces y enumeraciones de TypeScript; incluye ejercicios con condicionales.
- `04-condicionales_bucles`: práctica de condicionales, `switch`, arreglos y ciclos.
- `05-funciones`: creación y reutilización de funciones, parámetros, valores de retorno y ejercicios con arreglos.
- `06-practica`: ejercicios de lógica y algoritmos con condicionales, funciones y ciclos.
- `07-arrays`: arreglos en JavaScript; acceso y modificación de elementos, métodos comunes y operaciones CRUD con `splice`. Incluye una guía en `documento.md`.
- `08-callbacks`: funciones callback y métodos de arreglos como `find`, `filter`, `forEach`, `map`, `reduce` y `sort`.
- `09-objectos`: objetos y arreglos de objetos en TypeScript; interfaces, propiedades, desestructuración, spread y operaciones con datos.
- `10-BOM`: interacción con el navegador mediante objetos como `window`, `location` y `navigator`, incluyendo eventos y geolocalización.

## Página inicial

El archivo `index.html` contiene una página de presentación sencilla y carga el ejemplo de `fundamentos/10-BOM/app.js`.

Los archivos `.js` y `.ts` de `fundamentos/` son ejercicios independientes: no todos están conectados a la página inicial. El repositorio está orientado al aprendizaje y no incluye una configuración de compilación o scripts para ejecutar los ejemplos de TypeScript.
