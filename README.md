# Ejercicios de JavaScript — Comisión Web14p

Repositorio de práctica para los fundamentos de JavaScript y TypeScript, desarrollado durante la cursada de la Comisión Web14p de RollingCode.

## Contenidos

Los ejercicios están organizados por tema dentro de `fundamentos/`:

- `01-variables`: declaración de variables y tipos de datos básicos.
- `02-operadores`: operadores de comparación y lógicos.
- `03-objetos_if`: objetos, interfaces, enumeraciones y condicionales.
- `04-condicionales_bucles`: condicionales, arreglos y ciclos.
- `05-funciones`: funciones, parámetros, valores de retorno y arreglos.

La página inicial del proyecto está en `index.html`.

## Cómo explorar el proyecto

Abrí `index.html` en un navegador para ver la página inicial. Los ejemplos de cada tema se encuentran en sus archivos `.ts` dentro de `fundamentos/`; por ahora son material de práctica independiente y no están conectados a la página.

El repositorio todavía no incluye configuración de compilación, dependencias ni scripts de ejecución.
