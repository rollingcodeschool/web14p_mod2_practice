Bienvenido a la práctica del DOM⚙️

El Modelo de Objetos del Documento (DOM) conecta las páginas web con scripts o lenguajes de programación al representar en memoria la estructura de un documento (como el HTML que define una página web).

Conceptos y uso

El Modelo de Objetos del Documento (DOM) es una interfaz de programación para documentos web. Representa la página de modo que los programas puedan cambiar la estructura, el estilo y el contenido del documento. El DOM representa el documento como nodos y objetos; de esta forma, los lenguajes de programación pueden interactuar con la página.

Una página web es un documento que puede visualizarse en la ventana del navegador o como código fuente HTML. En ambos casos se trata del mismo documento, pero la representación mediante el Modelo de Objetos del Documento (DOM) permite manipularlo. Al ser una representación de la página web orientada a objetos, se puede modificar con un lenguaje de scripting, como JavaScript.
